# Joint Embedding Variational Bayes [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/aoji/vje/blob/main/VJE-DEMO.ipynb)

For an interactive walkthrough of the method, see the [companion webpage](https://aoji.github.io/vje/).
